Turn external websites, portals, dashboards, and tools into Odoo menus that open inside an iframe view.
External Tools in Odoo

Embed External Websites as Odoo Menus

Define iframe entries with a name, URL, company, parent menu, sequence, and optional icon. Each entry builds a real Odoo menu that opens the external website inside the Odoo backend, next to your native apps.

Multiple Menus

Create as many iframe menus as you need, each with its own URL.

Parent Menu or App Menu

Leave Parent Menu empty for a top-level app, or choose any existing parent menu.

Custom App Icon

Top-level iframe menus can use their own icon for a clean dashboard look.

Important Iframe Note

Some websites block iframe embedding with their own security policy. If a website shows a refused to connect message, that website does not allow iframe embedding. Use URLs that allow iframe embedding, such as your own website, internal portals, public dashboards, or embeddable tools.
